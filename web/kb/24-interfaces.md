# 24. Interfaces

How humans and systems actually reach the model. Children enumerate **surfaces**: chat UI, API, CLI, IDE, browser, mobile, voice, multimodal, and autonomous background workers. The axis is *mode of interaction* — from synchronous human chat to fully autonomous unattended operation. Worth distinguishing from tooling: tools are how the model reaches *out*; interfaces are how the world reaches *in*.
